# HomeVista – Real Estate Website

A modern and responsive real estate website built with WordPress, designed to showcase properties and provide a clean and user-friendly browsing experience.

## Project Overview

HomeVista is a real estate website created as part of my web development portfolio. The project focuses on a clean layout, easy navigation, and a professional design suitable for a real estate business.

The website includes property listings, agent information, FAQs, contact information, and other essential sections.

## Features

* Modern and clean real estate design
* Responsive layout for desktop and mobile
* Property listing sections
* Modern houses, apartments, and offices
* Agents page
* FAQ page
* Contact page
* About Us page
* Clean navigation and footer
* User-friendly interface

## Technologies Used

1. WordPress
2. Elementor

## Pages

* Home
* About Us
* Properties
* Agents
* FAQ
* Contact Us

## Purpose

This project was created as a portfolio project to demonstrate my skills in WordPress website development, web design, layout customization, and responsive design.
